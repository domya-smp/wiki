*Цитрусно-ягодный микс с пенкой. Прекрасный выбор для весёлого вечера с друзьями.*

**Автор рецепта:** GooseyG228

:::note[Краткая справка]
**Сложность:** 5 · **Опьянение:** 2 · **Бочка:** не нужна
:::

## Ингредиенты

| Предмет | Количество |
|---|---|
| Сладкие ягоды | 5 |
| Яйцо / Голубое яйцо / Коричневое яйцо | 3 |
| Сахарный тростник | 2 |
| Снежок | 1 |

## Параметры

- **Цвет:** розовый
- **Время варки:** 3 мин
- **Выдержка:** не требуется
- **Дистилляция:** 2 цикла по 40 секунд

## Эффекты

| Эффект | Уровень | Длительность |
|---|---|---|
| Регенерация | III | 100–120 сек |
| Огнестойкость | I | 200–220 сек |

*Диапазон длительности зависит от качества напитка: меньшее значение при худшем, большее — при идеальном.*

*Используйте 3 яйца одного вида: обычные, голубые или коричневые. Смешивание разных видов яиц не предусмотрено рецептом.*
